# EduPage for Home Assistant

This custom integration imports data from the [EduPage](https://www.edupage.org/) school information system into Home Assistant. It provides calendars for lessons and canteen meals, sensors for grades and notifications, and data that can be used in dashboards, templates, scripts, and automations.

The integration is based on the [edupage-api](https://github.com/EdupageAPI/edupage-api) Python library.

> [!IMPORTANT]
> This is an unofficial community integration. It is not affiliated with or supported by EduPage. Available data depends on the features enabled by your school and on the account used to sign in.

## Features

The current release provides:

- a lesson calendar containing the student's timetable;
- a canteen calendar when meal data is available;
- one sensor for each school subject, with grades stored as attributes;
- a notification sensor, with homework details stored as attributes;
- support for multiple students by creating a separate config entry for each student.

Features currently being developed in open pull requests include modern app-code two-factor authentication, structured notification events, meal and messaging services, substitution information, missing-teacher and next-ringing sensors, and term-average sensors. These features are not part of the current release until the respective pull requests have been reviewed and merged.

3. Search for **EduPage** or **homeassistantedupage**.

## Configuration

1. In Home Assistant, open **Settings â†’ Devices & services**.
2. Select **Add integration**.
3. Search for **EduPage**.
4. Enter your EduPage username, password, and school subdomain.
5. Select the student whose data should be imported.

For a school URL such as `https://example.edupage.org`, enter `example` as the subdomain.

If an account contains multiple students, create an additional config entry for every student you want to expose in Home Assistant.

## What is created?

The exact entity IDs are generated by Home Assistant and may differ from the examples below.

| Entity | Purpose | Where the detailed data is stored |
| --- | --- | --- |
| Lesson calendar | Timetable, including cancelled lessons | Calendar events |
| Canteen calendar | Snack, lunch, and afternoon snack | Calendar events |
| Subject sensors | Number of imported grades per subject | Sensor attributes |
| Notification sensor | Number of imported homework notifications | Sensor attributes |

Seeing many entities after setup is expected. EduPage exposes every school subject separately, so the integration creates one grade sensor for each subject returned by the school. Some schools also return class-like entries as subjects.

## Calendars and timetable data

Open **Calendar** in the Home Assistant sidebar to see the complete imported timetable. The state and attributes of a calendar entity normally describe only the event that is active now or comes next. This does not mean that the other lessons are missing.

To display the timetable on a dashboard, add Home Assistant's built-in calendar card:

```yaml
type: calendar
entities:
  - calendar.edupage_student_name
initial_view: listWeek
```

Replace the entity ID with the calendar entity created on your system.

### Retrieving all events in an automation

Use the `calendar.get_events` action when a script or automation needs more than the next event:

```yaml
action: calendar.get_events
target:
  entity_id: calendar.edupage_student_name
data:
  duration:
    hours: 24
response_variable: school_agenda
```

The returned `school_agenda` variable contains the events for the requested period. It can be processed by subsequent template actions, for example to determine the first lesson of the day and use it for an alarm automation.

For details about the action response, see the [Home Assistant calendar documentation](https://www.home-assistant.io/integrations/calendar/).

## Grade sensors

The integration creates a sensor for every subject. The sensor state is the number of imported grades for that subject. Grade details are stored as numbered attributes, for example:

```yaml
student:
  id: "12345"
  name: Example Student
grade_1_title: Written test
grade_1_grade_n: 2
grade_1_date: "2026-08-20 08:00:00"
grade_1_teacher: Example Teacher
```

Depending on the data supplied by the school, additional attributes may include maximum points, percentage, class average, and the teacher's comment.

You can inspect these attributes under **Developer tools â†’ States** by selecting the relevant subject sensor.

Example template:

```jinja2
{{ state_attr('sensor.edupage_subject_12345_example_student_mathematics',
              'grade_1_grade_n') }}
```

## Notifications and homework

The notification sensor state is the number of imported homework notifications. The current release exposes homework details as numbered attributes such as:

- `event_1_id`
- `event_1_text`
- `event_1_timestamp`
- `event_1_deadline`
- `event_1_author`
- `event_1_subject`

Inspect the sensor under **Developer tools â†’ States** to find its actual entity ID and available attributes.

Example Markdown card:

```yaml
type: markdown
title: Latest EduPage homework
content: >-
  {% set entity = 'sensor.edupage_notification_12345_example_student' %}
  {% if states(entity) | int(0) > 0 %}
    **{{ state_attr(entity, 'event_1_subject') or 'Homework' }}**

    {{ state_attr(entity, 'event_1_text') }}

    Deadline: {{ state_attr(entity, 'event_1_deadline') or 'not provided' }}
  {% else %}
    No homework notifications available.
  {% endif %}
```

There is currently no dedicated EduPage Lovelace card. Standard Home Assistant entity, calendar, Markdown, and template cards can be used to display the imported data.

## Canteen calendar

When the school account provides canteen data, a second calendar is created. It contains available snack, lunch, and afternoon-snack entries. It can be displayed with the same calendar card and queried with the same `calendar.get_events` action as the lesson calendar.

If no canteen calendar appears, verify that meals are visible for the same account in EduPage. Not every school uses this feature, and an empty or unavailable menu may prevent the current release from creating the calendar.

## Update interval

EduPage data is fetched from the cloud approximately every 30 minutes. Calendar data is currently requested for the next 14 days. Updates are therefore not instantaneous.

## Troubleshooting

### No entities appear

- Restart Home Assistant after installing the integration.
- Check **Settings â†’ System â†’ Logs** for messages containing `homeassistantedupage`.
- Confirm that the school subdomain and credentials are correct.
- Verify that the selected account can see student data in EduPage.

### Only the next calendar event is visible in the entity state

This is normal Home Assistant calendar behavior. Open the Calendar panel, use a calendar card, or call `calendar.get_events` to retrieve all events for a period.

### A grade sensor exists but has no grade attributes

The school may expose the subject without publishing any grades for it. The sensor will report that no grades are available yet.

### Notifications are missing

The current release imports homework-type notifications. Other EduPage message and event types may not be represented. Support for aggregated notification types is being developed separately.

### Two-factor authentication fails

The current release relies on the two-factor flow supported by its pinned `edupage-api` version. A newer app-code flow is under development in [pull request #96](https://github.com/rine77/homeassistantedupage/pull/96).

## Privacy and security

The integration communicates with your school's EduPage instance and stores the credentials or session data required by the installed integration version in the Home Assistant config entry. Protect your Home Assistant configuration and backups accordingly.

Do not include usernames, passwords, session IDs, student names, grades, message contents, or diagnostic logs containing personal information in public issues.

## Reporting a problem

Before opening an issue:

1. update the integration to the latest release;
2. restart Home Assistant;
3. check the Home Assistant logs;
4. search the [existing issues](https://github.com/rine77/homeassistantedupage/issues).

When creating a new issue, include:

- the integration version;
- the Home Assistant version;
- a concise description of the expected and actual behavior;
- relevant sanitized log messages;
- whether the account uses two-factor authentication;
- which EduPage features are enabled by the school.

Never post credentials, PHP session IDs, or personally identifiable school data.
